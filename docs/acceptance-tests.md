# 驗收清單

本文件描述預期情境，尚未執行測試。標示「建議規則」者來自規劃建議，其餘依簡報核心要求整理。

## 核心功能

- [ ] 新增稿件後，作者清單顯示正確的類別、標題與編輯中狀態。
- [ ] 編輯稿件後，類別、標題及文章內容正確儲存。
- [ ] 刪除編輯中稿件後，該稿件從清單移除。
- [ ] 送出編輯中稿件後，狀態變成審查中。
- [ ] 編輯待審查清單顯示作者、類別及標題。
- [ ] 編輯開啟稿件後，可以查看完整文章內容。
- [ ] 編輯退回後，狀態變為編輯中。
- [ ] 編輯通過後，狀態變為已通過。

## 建議規則

- [ ] 退回稿件可由作者修改並再次送出。
- [ ] 通過或退回後，稿件從待審查清單移除。
- [ ] 審查中與已通過稿件不能由作者修改、刪除或再次送出。
- [ ] 作者無法讀取或操作其他作者的稿件。
- [ ] 作者無法執行編輯審查操作。
- [ ] 編輯無法通過或退回非審查中稿件。
- [ ] 任一必填欄位為空或僅含空白時，阻止儲存與送出並提示原因。
- [ ] 取消刪除確認後，稿件仍然保留。
- [ ] 已通過稿件仍可依角色權限查看。
- [ ] 重新整理畫面後，已儲存資料與狀態仍正確。
- [ ] 若有後端，繞過畫面直接請求不合法操作時，後端仍會拒絕。
