# 初版實作紀錄

## 範圍

已完成簡報列出的作者清單、新增／編輯、刪除編輯中稿件、送出；以及編輯待審查清單、查看內容、通過與退回。頁面用彈出視窗整合表單與詳細內容，沒有分成四個獨立網址。

資料以瀏覽器 localStorage 實作，不包含真正登入與後端。UI 與核心函式皆檢查可執行的角色、所有權及狀態，但這些是示範流程限制。

## 已執行驗證

- 核心規則 6 組自動測試通過。
- JavaScript 語法檢查與靜態建置通過。
- 瀏覽器實際操作新增、送出、退回、修改、再送出、通過。
- 通過後只可查看，重新整理仍保留稿件。
- 空白標題阻止儲存；特殊 HTML 字元以文字顯示。
- 取消刪除保留稿件；確認刪除移除稿件。
- 搜尋無結果時顯示清楚提示。
- 檢查手機寬度下的排版與頁面橫向溢出。
