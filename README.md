# 投稿審查系統

依據「1151 期中個人專題」簡報整理的個人專題規劃。核心功能為作者管理投稿、編輯審查，以及稿件狀態轉換。

## 目前進度

本儲存庫目前提供規劃文件，尚未實作可執行系統。技術框架、正式繳交期限與繳交格式待確認。

## 文件導覽

- [需求規格](docs/requirements.md)：原始要求、建議規則、畫面與資料設計。
- [開發計畫](docs/development-plan.md)：七天時程、工作清單與展示安排。
- [驗收清單](docs/acceptance-tests.md)：核心功能與建議限制的測試情境。

## 核心流程

作者新增稿件 → 編輯中 → 送出投稿 → 審查中。

編輯審查：通過 → 已通過；退回 → 編輯中 → 作者修改並再次送出。

## 需求來源與界線

來源：使用者提供的「1151 期中個人專題.pptx」第 1 頁。

文件明確區分簡報原始要求與實作建議。七天時程為規劃假設，並非老師指定期限。原始簡報不包含在本專案內。
